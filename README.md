# Shrabin – UI/UX Portfolio

Static site: plain HTML, CSS and images. No build step.

- `index.html` – home page (about, case studies, graphic hub, contact)
- `resume.html` – resume page with an embedded PDF viewer (`files/Shrabin-Resume.pdf`)
- `rentica.html`, `oi-avatar.html`, `yumnum.html`, `teddy-ai.html` – case study pages
- `css/` – stylesheets (`home.css`, `case-study.css`)
- `images/` – all images

## Deploy with GitHub Pages
1. Replace the contents of your repository with these files (keep `index.html` in the root).
2. Repo Settings > Pages > Deploy from a branch > `main` / root.
3. Your site appears at `https://<username>.github.io/<repo>/`.

Fonts (Quicksand, Manrope) load from Google Fonts, so they need an internet connection.
